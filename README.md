# Hotel Management System

> Hotel management web app for rooms, guests, reservations and reports.

HotelManagement to system zarządzania hotelem, który pozwala na efektywne zarządzanie rezerwacjami, pokojami oraz danymi gości. Projekt zrealizowany przy użyciu Java oraz frameworka Spring Boot, zapewniający łatwą integrację z bazą danych i REST API.

## Technologie

- **Java 11**
- **Spring Boot 2.x**
- **Spring Data JPA**
- **MySQL** (lub inna baza danych, jeśli używasz innej)
- **REST API**
- **Maven** - do zarządzania zależnościami
- **JUnit** - do testowania aplikacji

## Funkcjonalności

- **Zarządzanie pokojami**: Tworzenie, edytowanie, usuwanie oraz wyświetlanie dostępnych pokoi.
- **Zarządzanie rezerwacjami**: Możliwość tworzenia nowych rezerwacji, edytowania ich, a także anulowania.
- **Zarządzanie danymi gości**: Możliwość dodawania, edytowania i usuwania danych gości.
- **Zarządzanie płatnościami**: Funkcjonalność do rejestrowania płatności za rezerwacje.
- **Statystyki**: Wyświetlanie raportów o dostępnych pokojach, rezerwacjach oraz płatnościach.
